# Скидка на доставку

Интерактивный прототип интерфейса управления скидками на доставку.

При обычном открытии после предзагрузки ресурсов появляется выбор режима просмотра, затем — выбор варианта «Без метрик» или «С метриками». После выбора основной прототип открывается с первого экрана.

Над устройством можно переключить вариант прототипа: без метрик или с данными об эффективности скидок.

- `?viewer=phone` — перейти к выбору варианта и открыть прототип на весь экран.
- `?viewer=desktop` — перейти к выбору варианта и открыть прототип в адаптивной рамке iPhone 375×812 px.

Локальный запуск:

```bash
python3 -m http.server 8765
```
