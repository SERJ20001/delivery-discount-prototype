# Скидка на доставку

[Открыть актуальный рублёвый прототип](https://serj20001.github.io/delivery-discount-prototype/rubles/)

Массовая настройка диапазонами, индивидуальные суммы товаров, подключение и редактирование действующих скидок. Пределы сохранены из прежней логики. При вводе вне пределов тултип показывает минимум или максимум, а подтверждение сохраняет допустимую границу без ошибки.

Исходники и инструкция: [README-RUBLES.md](README-RUBLES.md). Рабочая папка — `rubles/`; сборка — `node source/build-rubles.mjs`.

Прежний прототип сохранён в корне репозитория.

---

Интерактивный прототип интерфейса управления скидками на доставку.

При обычном открытии после предзагрузки ресурсов появляется выбор режима просмотра, затем — выбор варианта «Без метрик» или «С метриками». После выбора основной прототип открывается с первого экрана.

Над устройством можно переключить вариант прототипа: без метрик или с данными об эффективности скидок.

- `?viewer=phone` — перейти к выбору варианта и открыть прототип на весь экран.
- `?viewer=desktop` — перейти к выбору варианта и открыть прототип в адаптивной рамке iPhone 375×812 px.

Локальный запуск:

```bash
python3 -m http.server 8765
```
