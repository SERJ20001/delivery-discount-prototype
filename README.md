# Скидка на доставку

Интерактивный прототип интерфейса управления скидками на доставку.

При обычном открытии после предзагрузки ресурсов появляется выбор режима просмотра.

Над устройством можно переключить вариант прототипа: без метрик или с данными об эффективности скидок.

- `?viewer=phone` — открыть прототип на весь экран.
- `?viewer=desktop` — открыть прототип в адаптивной рамке iPhone 375×812 px.

Локальный запуск:

```bash
python3 -m http.server 8765
```
